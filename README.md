### Project Title: Mini To-Do List App

**Project Description:**

A simple and responsive To-Do List web application built using HTML, CSS, and JavaScript with the help of Cursor AI. It allows users to add tasks, mark them as completed, delete tasks, and track pending tasks. The application uses localStorage to save tasks even after refreshing the page and features a clean, minimal pastel-pink and white design. This project demonstrates AI-assisted development, debugging, and iterative feature enhancement using Cursor.
